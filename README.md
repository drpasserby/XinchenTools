# 心尘的工具集

> 一个集合多个实用工具网站的导航站点，基于 Vite + Vue 3 + Element Plus 构建

## 项目简介

心尘的工具集是一个聚合各类实用网站工具的在线导航平台，收录了来自互联网的优质工具站点。用户可以浏览、搜索、收藏、分享各类工具，支持随机抽卡发现新工具，提供网站预览等功能。

**在线访问**：[https://my.wulvxinchen.cn/tools/](https://my.wulvxinchen.cn/tools/)

## 核心功能

### 🔍 工具浏览与搜索
- **分类浏览**：按类型（工具、实用、趣味、游戏、资源、其他）筛选工具
- **实时搜索**：输入关键词即时显示匹配结果，支持名称、类型、简介、网址全字段搜索
- **全量搜索**：在独立弹窗中查看完整搜索结果列表
- **快捷标签**：一键点击预设分类标签快速筛选

### 🎲 随机发现
- **随机抽卡**：点击随机展示一个工具，适合探索新工具
- **首页自动抽卡**：可在设置中开启进入首页时自动随机展示

### ⭐ 本地收藏夹
- **收藏/取消收藏**：点击工具卡片或详情页的收藏按钮
- **本地存储**：收藏数据保存在浏览器 localStorage，仅当前设备/浏览器有效
- **收藏管理**：在收藏夹弹窗中查看、打开、移除收藏的工具

### 📄 工具详情页
访问 `/page?id=<工具ID>` 查看单个工具完整信息：
- 工具名称、类型、数据库 ID、简介、访问链接
- 收藏、分享、预览、直接访问操作
- 上一个/下一个工具快速切换
- **自动跳转**：分享链接可携带 `auto=1` 参数，配合设置中的延迟时间自动跳转

### 🖼️ 网站预览
- 通过第三方截图服务生成网站缩略图预览
- 支持在新窗口打开大图预览

### 🔗 分享功能
- 一键复制工具专属链接到剪贴板
- 可选是否包含自动跳转参数

### ⚙️ 个性化设置
在「关于」页面配置（仅当前设备/浏览器生效）：
- **分享链接自动跳转**：开启后分享链接携带 `auto=1` 参数
- **跳转延迟时间**：自动跳转前的等待毫秒数（默认 3000ms）
- **首页自动抽卡**：打开首页时自动随机展示一个工具
- **清空收藏夹**：一键清除本地所有收藏数据

## 使用指南

### 快速开始
1. 访问 [工具集首页](https://my.wulvxinchen.cn/tools/)
2. 浏览工具卡片，点击「详情」查看完整信息
3. 点击「访问」直接打开工具网站
4. 使用顶部搜索框或分类标签快速查找所需工具

### 收藏工具
1. 在工具卡片或详情弹窗点击「收藏」按钮
2. 点击顶部工具栏「收藏夹」查看已收藏工具
3. 收藏数据自动保存到浏览器本地，换设备/浏览器不同步

### 分享工具
1. 在工具详情弹窗点击「分享」按钮
2. 链接自动复制到剪贴板，格式：`https://域名/page?id=工具ID[&auto=1]`
3. 发送给他人，对方打开即可查看该工具详情

### 自定义体验
1. 点击导航栏「关于」进入设置页面
2. 根据需求调整自动跳转、延迟时间、首页抽卡等选项
3. 点击「保存」生效，或「恢复默认设置」重置

## 页面路由

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | 首页 | 工具列表、搜索、随机抽卡、收藏夹 |
| `/about` | 关于 | 项目介绍、设置、赞助、技术栈鸣谢 |
| `/page?id=<ID>` | 工具详情 | 单个工具完整信息、操作、预览 |
| `/login` | 登录 | 管理员登录入口（需账号权限） |
| `/admin` | 控制面板 | 管理员后台（需登录） |

## 技术栈

- **前端框架**：Vue 3 (Composition API)
- **构建工具**：Vite
- **UI 组件库**：Element Plus
- **路由**：Vue Router 4
- **HTTP 客户端**：Axios
- **后端**：Node.js + Express 5 + MySQL (mysql2)
- **语言**：中文界面

## 项目结构

```
server/                 # Node.js 后端
├── src/
│   ├── routes/         # auth / tools / admin 接口
│   ├── db/             # MySQL 与本地 Mock 数据层
│   ├── lib/            # 校验、密码、错误处理
│   ├── app.js          # Express 应用
│   └── server.js       # 启动入口
├── test/               # 接口集成测试
└── .env.example        # 环境变量模板

src/
├── api/
│   └── client.js       # Axios 实例（统一 API 基址）
├── views/
│   ├── Home.vue        # 首页 - 工具列表、搜索、收藏
│   ├── About.vue       # 关于页 - 设置、赞助、鸣谢
│   ├── Page.vue        # 详情页 - 单工具展示、操作
│   ├── Login.vue       # 登录页 - 管理员认证
│   └── Admin.vue       # 后台 - 工具/统计/Cookie 管理
├── router/index.js     # 路由配置
├── main.js             # 入口文件
├── App.vue             # 根组件
└── style.css           # 全局样式
```
